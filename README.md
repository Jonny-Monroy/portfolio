# Jonny Monroy · Portafolio Web

Sitio one-pager estático (HTML/CSS/JS puro, sin frameworks ni build) publicado con **GitHub Pages**.

- `index.html` — hero, métricas clave, proyectos, experiencia, habilidades, educación y contacto
- `assets/css/styles.css` — tema oscuro responsive con acentos en verde `#1B9E77`
- `assets/js/main.js` — animación de aparición al hacer scroll (IntersectionObserver)

## Publicar

1. Crear repo `portfolio` en GitHub y subir el contenido de esta carpeta.
2. Settings → Pages → Source: `main` → `/ (root)`.
3. URL pública: `https://jonny-monroy.github.io/portfolio/`

## Mantener

Los enlaces de proyectos apuntan a `github.com/Jonny-Monroy/*`. Al publicar repos nuevos,
actualizar las tarjetas en `#proyectos` y las métricas del hero.
